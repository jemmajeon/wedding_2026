💄 스드메 — 업체 진행 현황

모베터쉬크 (드레스) 협의 완료
  • 촬영용 블랙 → 베이지 교체 성공 (추가금 5만원으로 협의 완료)
  • 베이지 기준으로 수선 예정 → 본식 당일 착용 전 재피팅 필수!
  • 당일 예복 15만원 취소 건 → 추후 별도 협의 가능 (급하지 않음)
폴라리스 (신랑 예복·키높이) 확인 필요
  • 키높이는 폴라리스에서 별도 대여 (모베터쉬크와 무관)
  • 신랑 키높이 270으로 준비 예정
  • ⚠️ 신부 핸드폰 번호 잘못 기재됨 → 수정 요청 필요
꾸띠원 (메이크업) 취소 후 재예약
  • 5/13 예약 취소 (메이크업 원장 교체 문제 → 말 바꾸기 이슈)
  • 타 업체 재예약 완료 — 새 예약처 정보 저장 필요
